# Deferred catalog proposals

Files in this directory are draft proposals retained for contributor review.
They are outside `catalog/` and are excluded from the stable catalog bundle and
its generated navigation. Their original draft lifecycle status and source
attribution remain in each document; placement here does not promote or qualify
their content.

The subdirectories preserve the former catalog paths so proposal-to-proposal
links remain local. Links to stable catalog concepts point back into
`catalog/`. These proposals are repository material, not requirements needed to
use the stable bundle. A later contribution may propose selected material for
the bundle after its content, evidence, and dependency review.
